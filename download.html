Download

DeviceBill is available as a Debian package for Debian and Ubuntu based systems.

Install with APT

Install DeviceBill with:

sudo apt install devicebill

Package file

The current Debian package is available here: devicebill_0.1.0_all.deb

Local package install

If you already downloaded the package file, install it directly with:

sudo apt install ./devicebill_0.1.0_all.deb
Package builds are produced by the project Makefile and published with the static site.
